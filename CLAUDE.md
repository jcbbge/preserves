# AI Collaboration Principles

When working on this project:

1. READ FIRST, CODE SECOND - Always examine existing code and principles before suggesting changes

2. RESPECT BOUNDARIES - Only modify files explicitly mentioned, and operate within a defined scope

3. BUILD ON DECISIONS - Each session builds on previous decisions; don't relitigate settled matters

4. COMPLETE CURRENT TASK - Stay focused on the current task until complete before suggesting new work

5. MAKE TRADE-OFFS EXPLICIT - When suggesting a choice, explicitly state the trade-offs involved
